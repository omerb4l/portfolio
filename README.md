# 👋 Selam, Ben Ömer! 

> "Kod yazarken kahveyi, debug yaparken sabrı tüketen bir öğrenci."

Bu repo, benim dijital dünyadaki ayak izim, yani **kişisel portfolyom.** Bir yandan vizelerle boğuşurken bir yandan da kendimi modern web teknolojilerinin derinliklerine atıyorum. Sürekli öğrenen, hata yapmaktan korkmayan ve her yeni projede çıtayı biraz daha yukarı taşıyan biriyim.

---

### 🛠️ Neler Kullandım?

Bu portfolyoyu oluştururken kullandığım ana araç gereçler:

* **Frontend:** HTML5, CSS3, JavaScript (veya kullandığın framework: React/Vue vb.)
* **Styling:** Tailwind CSS / SCSS
* **Deployment:** Vercel / Netlify
* **Magic:** Bolca kahve ve merak!

---

### 🎯 Bu Projenin Amacı Ne?

* 🚀 Kendimi ve yaptığım işleri en şık şekilde tanıtmak.
* 💻 Modern web teknolojilerini pratik ederek "endüstri standardına" yaklaşmak.
* 💼 İş veya staj başvurularında "bakın ben boş durmuyorum" diyebilmek.
* 🌑 Karanlık modun (Dark Mode) kutsallığını her yere yaymak.

---

### 🚀 Local'de Çalıştırma

Projeyi kendi bilgisayarında incelemek istersen şu adımları izleyebilirsin:

```bash
# Repoyu klonla
git clone [https://github.com/omerb4l/portfolio.git](https://github.com/omerb4l/portfolio.git)

# Proje klasörüne gir
cd portfolio

# Bağımlılıkları yükle (npm kullanıyorsan)
npm install

# Projeyi ayağa kaldır
npm run dev
